# Support / 支持

## 获取帮助 / Getting Help

中文：先运行 `zlib-cli doctor --json`，并阅读 README 的“域名变化与不可访问”部分。确认是
可复现的项目问题后，使用 GitHub Bug Report 模板。

English: Run `zlib-cli doctor --json` and read the README section on changing and
unreachable domains. If the problem is reproducible and project-related, use the GitHub bug
report template.

提交前请删除或替换以下内容：

Remove or replace all of the following before posting:

- 真实邮箱、账号名、token、cookie 和密码 / Real email addresses, account names, tokens,
  cookies, and passwords.
- 配置文件内容和用户主目录路径 / Config contents and identifying home-directory paths.
- 带 token、key 或私人参数的下载 URL / Download URLs containing tokens, keys, or private parameters.
- 下载的电子书及其内容 / Downloaded ebooks and their contents.

## 支持范围 / Support Scope

项目可以处理 CLI 缺陷、解析回归、JSON 协议、安装、打包和文档问题。上游服务封锁、账号
限制、验证码和镜像下线不由本项目控制，但诊断信息不清楚仍可作为项目问题反馈。

The project can address CLI bugs, parser regressions, JSON contracts, installation,
packaging, and documentation. Upstream blocking, account restrictions, captchas, and mirror
shutdowns are outside project control, but unclear diagnostics are still valid project bugs.

安全问题不要走普通 Issue，按 [SECURITY.md](SECURITY.md) 私密报告。

Do not use a normal issue for security vulnerabilities; follow [SECURITY.md](SECURITY.md).
